# آزمون‌ها و نتایج واقعی — NumberBank

## ۱) چگونه اجرا می‌شوند

```bash
make test                            # آزمون‌های واحد و یکپارچه (کاملاً آفلاین)
make test-live                       # آزمون‌های زنده (نیازمند اینترنت آزاد)
.venv/bin/numberbank selftest        # پذیرش سرتاسری روی دیتابیس موقت
```

## ۲) پوشش آزمون‌ها (۵۴ آزمون + ۲ آزمون زنده)

| فایل | آنچه واقعاً بررسی می‌کند |
|---|---|
| `tests/unit/test_phones_normalize.py` | تجزیه شماره ثابت/موبایل/خدماتی، پیش‌شماره، شماره محلی ۷ و ۸ رقمی، رد شماره‌های ناممکن و تکراری، تشخیص بلوک مصنوعی |
| `tests/unit/test_relevance_lexicon.py` | دسته/نقش درست برای ۵ نمونه واقعی + رد ۴ متن نامرتبط (استخدام، پخش زنده فوتبال، …) |
| `tests/unit/test_similarity_guards.py` | جلوگیری از ادغام نادرست کسب‌وکارهای هم‌ساختار و پذیرش تکراری واقعی |
| `tests/unit/test_gazetteer.py` | تطبیق «بندر گز»↔«بندرگز»، شهر سه‌حرفی «خاش»، نپذیرفتن «مرکزی» بدون زمینه، سازگاری استان/شهرستان/شهر، پیش‌شماره |
| `tests/unit/test_extract_directory_page.py` | صفحه دایرکتوری ⇒ کاندید جدا برای هر کسب‌وکار؛ شماره‌های چسبیده جدا می‌شوند؛ ارقام فارسی؛ کد پستی اشتباه گرفته نمی‌شود؛ صفحه اسپم علامت می‌خورد |
| `tests/unit/test_confidence_bands.py` | یکنوایی باندها با شواهد، جریمه الگوی جعلی، وجود ریزاجزا |
| `tests/integration/test_persist_pipeline.py` | ذخیره + شواهد + عدم انتساب متقابل شماره، بی‌اثری اجرای مجدد، ثبت (نه ذخیره) کاندید نامرتبط، بازاعتبارسنجی «سررسیده» + ثبت `ValidationHistory` |
| `tests/integration/test_dedup_merge.py` | ادغام واقعی دو رکورد از دو منبع، حفظ همه شواهد، و **عدم** ادغام نام‌های مشابه |
| `tests/integration/test_end_to_end_demo.py` | اجرای کامل دمو (۲ اجرا) و بررسی تک‌تک ۸ معیار پذیرش + نبود شماره تکراری + شاهد برای هر رکورد |
| `tests/live/test_live_sources.py` | موتور جستجوی واقعی نتیجه برمی‌گرداند؛ در حالت زنده منبع آزمایشی فعال نیست |

> آزمون‌های `live` به‌صورت پیش‌فرض **skip** می‌شوند (شبکه لازم است) و با `NUMBERBANK_RUN_LIVE=1` اجرا می‌شوند.

## ۴) اشکالات واقعی که در همین آزمون‌ها کشف و رفع شدند

1. **ادغام نادرست کسب‌وکارهای هم‌ساختار** — `token_set_ratio` روی نام‌های فاقد فاصله، «شرکت عمده
   فروشی محصولات بهداشتی حسینی» و «… رحیمی» را ۰٫۹ مشابه می‌دید ⇒ ۱۳۷ ادغام نادرست.
   رفع: شباهت **واژه‌های متمایزکننده** + الزام «لنگر هویتی» ⇒ ۴۵ ادغام درست.
2. **تطبیق مکان ناقص** — نام‌های چندکلمه‌ای («بندر گز») و سه‌حرفی («خاش») هرگز تطبیق نمی‌شدند و
   شهرِ نادرست از زمینه پرس‌وجو به رکورد می‌چسبید. رفع: تطبیق روی متن بدون جداکننده با نگاشت
   اندیس + بررسی مرز واژه + انتخاب سازگار استان/شهرستان/شهر.
3. **استخراج شماره‌های چسبیده** — توالی «09120000000 09120000001» یک عدد واحد دیده می‌شد و ارقام
   فارسی در HTML نادیده می‌ماند. رفع: تقسیم ناحیه به شماره‌های مستقل + نرمال‌سازی ارقام.
4. **صفحه دایرکتوری به‌عنوان یک کسب‌وکار** — کل فهرست یک کاندید می‌شد و ۱۴۲ شاهد به یک رکورد
   می‌چسبید. رفع: انتخاب بلوک‌های درونی‌ترین (innermost) و شمارش شماره‌ها در هر بلوک.
5. **وضعیت پایانی Job ثبت نمی‌شد** (همیشه PENDING/دائماً «فعال» شمرده می‌شد). رفع: ثبت قطعی
   `DONE/CANCELLED/FAILED` در `finally`.
6. **`UNIQUE constraint failed: source_observations.dedupe_hash`** در اجرای موازی. رفع: مجموعه
   حافظه‌ای + `autoflush` + تلاش مجدد رکوردبه‌رکورد.
7. **`.where(None)` در SQLAlchemy 2.1** باعث شمارش صفر می‌شد. رفع: `true()`.
8. **شماره‌های محلی ۷ رقمی** حل نمی‌شدند. رفع: پذیرش ۷ و ۸ رقم با علامت‌گذاری «استنباط‌شده».
9. **پیوند مکانی رکوردها** (`city_id/county_id/province_id`) هرگز پر نمی‌شد. رفع: نمایه مکان‌ها و
   اتصال بدون حدس (۲۰۵ از ۲۰۵ رکورد شهر، ۲۰۳ شهرستان).
10. **`DiscoveryError` و `url` تعریف‌نشده** (خطاهای نهفته که در مسیرهای کم‌تکرار رخ می‌دادند) —
    با lint کشف و رفع شد.
11. **بازاعتبارسنجی در پذیرش هرگز واقعاً اجرا نمی‌شد** — چون هیچ شماره‌ای بلافاصله پس از کشف
    «سررسیده» نیست، `selftest` عدد صفر می‌گرفت (۱۲ از ۱۳). رفع: افزودن `expire_validations`
    برای سررسید کردن واقعی + سنجش `ValidationHistory` (نه فقط شمارش) و افزودن آزمون یکپارچه
    `test_expired_phones_are_revalidated_and_history_written` که هر دو حالت «سررسیده» و
    «سررسیدنشده» را بررسی می‌کند ⇒ اکنون **۱۳ از ۱۳**.

## ۵) آنچه در این محیط قابل آزمون نبود

* خزش واقعی اینترنت (موتورهای جستجو و سایت‌های ایرانی در سندباکس مسدودند): کد مسیر واقعی
  نوشته و lint/import شده است، اما اثبات کارکرد آن به اجرای `make test-live` روی شبکه آزاد
  موکول است. مسیر قابل‌اثبات در این محیط، **پیکره آزمایشی آفلاین** است که همه اجزای زنجیره
  (کشف → استخراج → ارتباط → امتیاز → ذخیره → یکتاسازی → خروجی → داشبورد) را واقعاً اجرا می‌کند.
